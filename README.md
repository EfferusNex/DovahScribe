Добро пожаловать в **DovahScribe** — современный профессиональный комплекс для локализации плагинов **The Elder Scrolls V: Skyrim (SE / AE / VR)** на русский язык.

DovahScribe объединяет передовые языковые модели (LLM), глубокий контекстный анализ графов диалогов, нативные инструменты сборки плагинов и автономный настольный CAT-интерфейс (Computer-Assisted Translation). Больше не нужно мириться с «корявым» машинным переводом, где реплики вырваны из контекста, девушки-спутницы говорят о себе в мужском роде, а термины переводятся как попало.

## 🌟 Ключевые возможности и архитектура (Features)

### 💬 1. Анализ графа диалогов и окно контекста (Dialogue Context Window)
- **Проблема:** Традиционные переводчики переводят строки изолированно, вслепую. Если персонаж говорит короткую фразу (*«Fine, take it»* или *«What about the ring?»*), без знания предыдущих реплик невозможно понять интонацию: сарказм это, угроза, покорность или торговая сделка.
- **Решение DovahScribe:** 
  - ИИ анализирует **диалоговые ветки целиком**, связывая родительский топик (`DialogTopic`) и дочерние реплики (`Responses`).
  - При переводе каждой реплики нейросеть получает **скользящее окно контекста из 2–3 соседних реплик диалога** (вопрос игрока, предшествующий ответ собеседника и текущая тема беседы).
  - Это обеспечивает естественные диалоги с сохранением сквозной нити разговора, живой эмоциональной окраски и правильных местоимений.

### 👩 2. Контекстно-ориентированный учет пола и ролей (Gender & Context Engine)
- **Проблема:** В английском языке глаголы прошедшего времени безличны (*«I found the relic»*). Обычные переводчики всегда сводят их к мужскому роду: *«Я нашёл реликвию»*.
- **Решение DovahScribe:** Движок парсит `NPC_` и `QUST` структуры плагина, извлекая пол, расу, тон диалога и имя спикера. Спутницы, торговки, бандитки и ярлы говорят в правильном грамматическом роде (*«Я нашла реликвию»*, *«Рада помочь тебе»*).

### 🧙‍♂️ 3. Каноничный словарь терминов и Anti-Trap система (Глоссарий)
- **Строгий лорный словарь TES:** Все школы магии (*Разрушение, Иллюзия*), даэдра, божества (*Акатош, Мара*), материалы (*Эбонит, Сталгрим*) и топонимы (*Вайтран, Солитьюд*) переводятся строго по канону официальной русской локализации Skyrim.
- **Интерактивный реестр ляпов (Anti-Trap):** Встроенная система защиты от ложных друзей переводчика:
  - `Race ➔ Раса` (не *гонка*)
  - `Staff ➔ Посох` (не *персонал*)
  - `Follower ➔ Спутник` (не *подписчик*)
  - `Cast ➔ Сотворение / Чтение` (не *гипс*)
  - `Chest ➔ Сундук` (не *грудь*)
  - `Hostile ➔ Враждебный` (не *хостел*)
  - Возможность мгновенной **1-клик санитизации** всего мода по правилам глоссария.

### 🛡️ 4. Защита игрового движка от вылетов и поломок тегов (Tag Guardian)
- Игровые теги подстановки (`<ALIAS=Player>`, `<Global=Gold>`, `<font color='#FF0000'>`, `[pagebreak]`, системные спецификаторы `%s`, `%d`, `%f`) надежно маскируются перед передачей в нейросеть.
- CAT-интерфейс в реальном времени валидирует целостность тегов и подсвечивает потерянные плейсхолдеры красным пульсирующим бейджем.

### ⚡ 5. Мгновенная память переводов (Translation Memory / Exact Match)
- В базу интегрирован официальный корпус строк Skyrim (более 68 000 ванильных фраз) и глобальная база переводов модов.
- Стандартные предметы, ванильные реплики и заклинания получают 100% официальный русский перевод мгновенно с нулевыми затратами токенов.

### 🖥️ 6. Настольный CAT-дашборд DovahScribe (PyWebView Desktop App)
- **Автономность:** Работает как нативное быстрое Windows-приложение на базе WebView2 (Chromium) — **не требует запуска сторонних веб-серверов** (Flask/Node.js).
- **Интерактивная навигация:** Клик по бейджу темы диалога мгновенно переносит фокус к родительской реплике с плавной анимацией подсветки.
- **Горячие клавиши и автосохранение:**
  - `Ctrl + S` / `Ctrl + Ы` — мгновенное прямое сохранение в `{mod}_review.json` на диск.
  - Фоновое автосохранение с debounce (2.5 сек) во время набора текста.
  - `Ctrl + Enter` — быстрый переход к следующей строке перевода.
  - `Alt + O` / `Alt + R` — возврат к оригиналу / сброс к ИИ-черновику.
  - `Ctrl + Left/Right` — быстрая пагинация по страницам.
- **Многоуровневая фильтрация:** 4 Quality Gate статуса (*Все, Без замечаний, Замечания, Без перевода*) + 6 категорий контента (*Диалоги, Сообщения, Квесты, Предметы, Магия, Книги*).

### 📦 7. 1-Click генерация ESP-патчей и деплой в MO2
- Экспорт чистого манифеста операций `{mod}_ops.json`.
- Прямой деплой мода в Mod Organizer 2 (`<ModName> [RU]`) с выставлением наивысшего приоритета перекрытия в `modlist.txt`.

## 🚀 Быстрый старт

### 1. Установка окружения
```bash
# Клонируйте репозиторий
git clone https://github.com/EfferusNex/DovahScribe.git
cd DovahScribe

# Установите зависимости
pip install -r requirements.txt

# Настройте переменные окружения
cp .env.example .env
```

### 2. Запуск интерфейса DovahScribe
Для запуска дашборда локализации (без черного консольного окна):
```cmd
run_dovahscribe.bat [ModName]
```
*Например:* `run_dovahscribe.bat MyCustomMod` или кликом по `DovahScribe.exe`.

### 3. Режим отладки (DevTools)
Если требуется инспектировать элементы интерфейса или консоль JS:
```cmd
python app.py MyCustomMod --debug
```

## 💬 Часто задаваемые вопросы (FAQ)

**В: Нужен ли установленный Skyrim для работы программы?**  
О: Нет, DovahScribe работает полностью автономно. Для сверки названий используются встроенные словари и контекстные базы.

**В: С какими форматами плагинов работает комплекс?**  
О: Поддерживаются любые плагины формата `.esp`, `.esm`, `.esl` для Skyrim Special Edition, Anniversary Edition и VR.

**В: Что произойдет, если автор обновит мод до новой версии?**  
О: Все подтвержденные и отредактированные вами переводы сохраняются в Translation Memory. При повторной обработке обновленного мода совпавшие строки применятся мгновенно и бесплатно.
